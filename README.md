# interval-paper-data

Simulation inputs (structures, topologies, and parameters) to reproduce the molecular dynamics simulations reported in:

Michael von Domaros, Rinto Thomas and Praveen Ranganath Prabhakar
**Bin size**, arXiv: 0000.00000 (2026).
https://arxiv.org/xxx/xxx

## Overview

This repository provides ready-to-run input decks for molecular dynamics simulations and analysis workflows associated with the interval determination of residence time approach from the previous study (https://doi.org/10.1021/acs.jctc.6c00645) 

The system directory is self-contained and includes the system coordinates, topology, parameters, and simulation configuration files used in the study.
